# Комментарии и варианты в шахматных досках

Доска читает комментарии из PGN и проговаривает их после хода. Альтернативная
линия пишется прямо в комментарии в скобках доллар — это замена хода, которую
можно проиграть клавишей V.

## Итальянская партия с вариантами

```chess
pgn=https://cdn.jsdelivr.net/gh/denizsincar29/chessjax@v0.8.7/examples/variations.pgn
move=3
```

Что попробовать:

- **Ctrl+← и Ctrl+→** — предыдущий и следующий ход; после хода с комментарием
  NVDA скажет «Комментарий: …» и подскажет «есть вариант — клавиша V проиграть».
- **V** — проиграть вариант, повторное **V** — финал, **Esc** — вернуться в партию.
- Клетки ходов варианта подсвечены оранжевой рамкой.

## Как это выглядит в разметке

Партия целиком задаётся ссылкой на файл PGN, а номер хода решает, где открыть
доску:

```
pgn=https://…/variations.pgn
move=3
```

Варианты и комментарии лежат в самом PGN рядом с ходом:

```
1. e4 e5 2. Nf3 { $[Bc4 Nc6] итальянская партия — слон давит на f7 } Nc6 …
```

Комментарий привязан к позиции после хода; вариант заменяет сам ход и стартует
с позиции до него.
