    Справка: как пользоваться редактором

    Формулы

    LaTeX пишется в долларах: $x^2$ — формула в строке, $$...$$ — на отдельной строке. Работают и скобки: \(...\) и \[...\].

    AsciiMath пишется в обратных кавычках: `sqrt(2)`. Это упрощённый язык: `sum_(i=1)^n`, греческие буквы — alpha, pi.

    Вставка формул кнопками

    Выделите текст и нажмите кнопку на панели — выделение обернётся в формулу. Без выделения кнопка вставит шаблон. Хоткеи: Alt+M — строка или блок, Alt+L — синтаксис LaTeX или AsciiMath, Alt+1..9 — вставить дробь, корень, сумму и другие структуры.

    Автодополнение

    Внутри формулы подсказки появляются сами: в LaTeX-делимитерах — латеховские команды (например, \frac, \sqrt), в AsciiMath — аскиматовские (sqrt, sum). Делимитеры, блоки, ключи настроек и разметка markdown — по Ctrl+Space.

    Настройки документа (frontmatter)

    Введите --- в начале пустого документа — блок настроек развернётся сам и закроется. В нём: title — заголовок, lang — язык (ru, en, de, tr), author, description. Модули подключаются сами по содержимому: есть блок ```chess — грузится шахматный компонент, есть ```desmos — грузится Desmos; mathjax включён по умолчанию.

    Графики и шахматы

    График Desmos — блок ```desmos, каждая строка — выражение, например y=x^2.

    Шахматная доска — блок ```chess с атрибутами. Минимум: ```chess fen="начальная позиция". Можно партию pgn="адрес" и номер хода move="10".

    Предпросмотр и клавиши

    Alt+ё — полный предпросмотр: пересоздать графики и перейти к строке курсора. Ctrl+Shift+Enter — скрыть предпросмотр. Текст предпросмотра обновляется при наборе.

    Файл и вывод

    Открыть .md — файл с диска, Скачать .md — сохранить исходник, Сохранить готовый HTML — скачать страницу для раздачи. Примеры открываются из списка «Пример:».

    Облако документов

    Alt+O — список документов в облаке: выбрать и открыть. Открытый из облака документ сохраняется туда же по Ctrl+S, Ctrl+Alt+S — сохранить под новым адресом в облаке. Ссылка #cloud=имя/путь открывает документ из облака сразу.
